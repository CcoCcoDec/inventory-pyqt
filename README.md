# PyQt5 기반 ERP 재고관리 프로그램

PyQt5와 MySQL을 활용해 구현한 데스크톱형 재고관리 프로그램입니다. 재고 데이터의 조회·검색·추가·수정·삭제 기능과 변경 이력 조회 기능을 제공하며, 로그인 화면을 통해 프로그램에 진입하도록 구성했습니다.

> 이 저장소는 학습 및 포트폴리오 소개를 위한 프로젝트입니다. 실제 업무 환경에 적용하기 전에는 인증·권한·비밀번호 저장 방식과 데이터베이스 운영 보안을 보완해야 합니다.

## 1. 프로젝트 기획

### 목표
- Python GUI 프레임워크인 PyQt5를 이용해 데스크톱 업무 프로그램을 구현합니다.
- MySQL 데이터베이스와 연동해 재고 정보를 영속적으로 관리합니다.
- 재고 데이터 변경 이력을 기록해 변경 내역을 추적할 수 있도록 합니다.
- 화면 구성, DB 접근 로직, SQL 스키마를 파일별로 분리해 구조를 이해하기 쉽게 구성합니다.

### 주요 사용자 흐름
1. 프로그램 실행 후 로그인합니다.
2. 메인 화면에서 재고 조회 또는 재고 이력 메뉴를 선택합니다.
3. 재고 화면에서 데이터를 조회·검색하거나 추가·수정·삭제합니다.
4. 재고 이력 화면에서 변경 작업과 처리 정보를 확인합니다.

## 2. 주요 기능

- **로그인:** MySQL `users` 테이블을 이용한 아이디·비밀번호 확인
- **재고 조회:** 재고 목록을 테이블 형태로 표시
- **재고 검색:** 관리번호, 분류, 자재명 기준 검색
- **재고 추가:** 입력한 재고 정보를 DB에 등록
- **재고 수정 및 삭제:** 선택한 재고 항목을 수정하거나 삭제
- **변경 이력 조회:** 재고 추가·수정·삭제 이력 확인 및 관리번호 기준 조회
- **테이블 정렬:** 열 제목을 클릭해 목록 정렬
- **공통 UI 스타일:** 화면에 공통 글꼴과 스타일 적용
- **버전 정보:** 프로그램 버전 정보를 표시

## 3. 기술 스택

| 구분 | 기술 |

## 4. 프로젝트 구조

```text
inventory-pyqt-master/
├── app.py                     # 프로그램 진입점 및 로그인 이후 화면 실행
├── login_dialog.py            # 로그인 창
├── main_window.py             # 메인 메뉴 화면
├── sub_window_erp.py          # 재고 조회·검색·추가·수정·삭제
├── sub_window_erp_history.py  # 재고 변경 이력 조회

├── ui_style.py                # 공통 UI 스타일
├── SQL_Scripts.sql            # 데이터베이스 및 테이블 초기화 SQL
├── assets/
│   └── erp_login_background.png
└── .gitignore
```

## 5. 구현 구조

### 화면 계층
- `app.py`가 `QApplication`을 생성하고 로그인 성공 여부에 따라 메인 화면을 실행합니다.
- `login_dialog.py`는 사용자 인증 화면을 담당합니다.
- `main_window.py`는 재고 조회, 재고 이력, 버전 정보 화면으로 이동하는 메뉴를 제공합니다.
- `sub_window_erp.py`와 `sub_window_erp_history.py`는 각각 재고 관리와 변경 이력 조회 UI를 담당합니다.

### 데이터 접근 계층
- `db_helper.py`의 `DB` 클래스가 MySQL 연결과 SQL 실행을 담당합니다.
- 화면 코드에서 DB 처리 로직을 직접 반복 작성하지 않고 `DB` 클래스의 메서드를 호출하도록 구성했습니다.
- 재고 변경 작업은 `erp_history` 테이블에 변경 전·후 정보와 작업 구분, 처리 시각, 등록자를 기록하도록 구현했습니다.

### 데이터베이스
- `users`: 로그인 사용자 정보
- `erp`: 재고 기본 정보
- `erp_history`: 재고 변경 이력

## 6. 실행 환경 및 설치

### 사전 준비
- Python 3.10 이상 권장
- MySQL Server
- pip

### 패키지 설치

프로젝트 폴더에서 가상환경 사용을 권장합니다.

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install PyQt5 PyMySQL
```

### 데이터베이스 초기화

1. MySQL Workbench 등에서 `SQL_Scripts.sql`을 엽니다.
2. SQL 스크립트를 실행해 `inventory` 데이터베이스와 테이블, 예제 데이터를 생성합니다.
3. 이미 같은 이름의 테이블에 데이터가 있다면 초기화 스크립트 실행 전 데이터를 백업하고 내용을 확인하세요.

### DB 접속 정보 설정

`db_helper.py` 상단의 다음 변수를 본인 환경에 맞게 수정합니다.

```python
DB_HOST = "localhost"
DB_PORT = 3306
DB_USER = "root"
DB_PASSWORD = "여기에_비밀번호_입력"
DB_NAME = "inventory"
```

**주의:** 공개 저장소에는 실제 DB 비밀번호를 입력한 파일을 커밋하지 마세요. 이 저장소의 `db_helper.py`는 공개용 자리표시자 값을 사용합니다. 실제 비밀번호를 입력한 상태로 커밋하면 비밀번호가 공개됩니다. `.gitignore`는 이미 Git에서 추적 중인 파일의 변경을 자동으로 숨기지 않습니다.

### 실행

```powershell
python app.py
```

초기 SQL에는 데모용 `admin` 계정이 포함되어 있습니다. 초기 로그인 정보는 `admin / admin`이며, 학습용 예제에 한정해 사용하세요. 실제 서비스에서는 평문 비밀번호 비교 및 기본 계정 사용을 피하고, 안전한 비밀번호 해시와 적절한 권한 관리를 구현해야 합니다.

## 7. 보안 및 사용상 유의점

- 실제 DB 비밀번호, 개인 이메일, 실명 등 개인정보를 공개 저장소에 포함하지 마세요.
- MySQL `root` 계정 대신 필요한 권한만 가진 전용 DB 계정을 사용하는 것이 좋습니다.
- 현재 로그인 구현은 학습용 단순 비교 방식입니다. 실제 서비스에 적합한 인증 구현은 아닙니다.
- 이 프로젝트는 로컬 개발 환경을 기준으로 하며, 원격 배포·운영 환경에서의 보안이나 가용성을 보장하지 않습니다.
- `SQL_Scripts.sql`은 개발용 예제 데이터가 포함된 스크립트입니다. 실제 데이터베이스에서 실행하기 전에 내용을 검토하세요.

## 8. 향후 개선 과제

- 비밀번호를 해시 방식으로 저장하고 인증 로직 보강
- DB 계정 권한 최소화 및 접속 정보의 안전한 외부화
- 입력값 검증과 예외 처리 개선
- DB 연결 오류를 사용자에게 명확하게 안내
- 단위 테스트 및 DB 연동 테스트 추가
- 재고 변경 이력의 무결성 및 사용자 권한 검증 강화
